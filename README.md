# Todo List

Веб-приложение для управления задачами с возможностью добавления, удаления и отметки выполнения. Реализовано на чистом HTML, CSS и JavaScript

В проекте используется localStorage для сохранения списка задач после перезагрузки страницы. JavaScript отвечает за динамическое отображение задач и обработку событий. Стили написаны на CSS.

**Технологии**: HTML5, CSS3, JavaScript.
